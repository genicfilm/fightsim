# The ledger

Every card this model has committed to, in public, before the fights.

Each receipt in this folder was written by EVENT mode and **committed before the event**, so
`git log` is the timestamp. Nothing here is a backtest. The model declines any fight it prices
under 0.58 — across 3,404 held-out fights those realised 52.0%, which is the whole reason the
refusals exist. They are graded here anyway, in their own column, because a refusal is only
honest if you can check that it really was a coin flip.

## No events yet
